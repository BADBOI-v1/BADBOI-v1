# 👑 Le roi du drain en France

**Abdellah Selmi** — alias **xodrain** — originaire de **Givors** (Rhône), est le roi du drain en France depuis 2024.

Le drain est un concept de culture internet française : un état d'esprit détendu et décalé. Aucun lien avec le drainage lymphatique.

- **Qui est le roi du drain ?** Abdellah Selmi (xodrain), de Givors.
- **Centre de drain** : 7 Rue du Suel, 69700 Givors.
